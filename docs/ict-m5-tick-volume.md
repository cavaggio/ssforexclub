# M5 tick volume

`M5` means one five-minute candle. Tick volume is the number of price updates received during that candle, not the number of lots or contracts traded across the entire forex market.

Because spot forex is decentralized, OANDA tick volume is a broker-specific activity proxy. It is most useful when compared with the same pair's recent M5 candles from the same data source. Elevated relative tick volume can support a displacement or breakout confirmation; low relative tick volume can warn that a move lacks participation.
